# Changelog

## 0.2.0

- Windows 10 2004+ compatibility, including classic taskbar item detection.
- Separate credits-balance display in English, Japanese and Simplified Chinese.
- Protected application assemblies with encrypted strings, symbol renaming, integer encoding and control-flow transformations.

## 0.1.0

- Native Windows taskbar widget and notification icon.
- Weekly and five-hour usage rings, with a weekly-only view for Pro accounts.
- English, Japanese, and Simplified Chinese interface.
- Light, dark, and system themes.
- Automatic reconnection, manual refresh, and local reset times.
- Optional startup at Windows sign-in.
